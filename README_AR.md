# بوصلتي (Bosalty) — نسخة Flutter

تحويل تطبيق `focus_tasks.py` (Python/customtkinter) إلى Flutter للموبايل.

## خطوات التشغيل وبناء الـ APK

1. ثبّت Flutter SDK و Android Studio (أو Android SDK) ثم تأكد: `flutter doctor`
2. أنشئ مشروع فاضي وانسخ ملفات المشروع فوقه:
   ```
   flutter create bosalty
   ```
   ثم انسخ **داخل** مجلد `bosalty` اللي اتعمل: فولدر `lib/` و`assets/` وملف `pubspec.yaml` (استبدل الموجود).
3. نزّل الحزم:
   ```
   flutter pub get
   ```
4. جرّب على موبايل/محاكي: `flutter run`
5. ابني الـ APK:
   ```
   flutter build apk --release
   ```
   الملف هيتعمل في: `build/app/outputs/flutter-apk/app-release.apk`
   (لو عايز حجم أصغر: `flutter build apk --split-per-abi`)

## اللي اتنقل من التطبيق الأصلي
- المهام (إضافة/تعديل/حذف/إنجاز، صعوبة وXP، تاريخ، ربط بهدف، تصفية بالمشروع واليوم)
- مؤقت التركيز + الجلسات + السجل (إحصائيات اليوم/الأسبوع/الشهر + تجميع بالأيام)
- الأهداف الشهرية + التقرير الشهري (نسخ للحافظة)
- نظام المستويات والشارات والتتابع (streak)
- مواقيت الصلاة (نفس معادلة الكود الأصلي — القاهرة)
- عربي/إنجليزي مع RTL، فاتح/داكن، ألوان رئيسية، تكبير الخطوط، كل الإعدادات الأساسية
- نفس صيغة بيانات JSON الأصلية (tasks, goals, sessions, xp, ...)

## اللي اتغير بسبب الموبايل
- إعدادات `timer_width` و`task_wrap` وقلب تخطيط شاشة التركيز اتشالت (خاصة بالديسكتوب).
- إشعار نهاية الجلسة بقى صوت + اهتزاز + رسالة داخل التطبيق (مش إشعار نظام). لو عايز إشعار حقيقي في الخلفية: `flutter_local_notifications`.
- حفظ البيانات في `shared_preferences` بدل ملف `tasks_data.json`.
- التقرير الشهري: نص قابل للنسخ (من غير تصدير .txt).
- الأيقونات والخطوط: من ملف الـ ZIP اللي بعتّه (خط Thmanyah للعناوين).
